# Archive

This folder holds one-off/scratch artifacts moved here by the
Housekeeping/Cleanup Agent (see `AGENTS.md` §12.39) at the end of a
finished work cycle — things like throwaway test scripts or exploratory
debug files that aren't part of the actual application.

**Nothing here was deleted.** Files are organized by the date of the
cycle they were archived from: `archive/<cycle-date>/<original-relative-path>`.

If something here turns out to still be needed, just move it back —
the Cleanup Agent never deletes, only relocates.
