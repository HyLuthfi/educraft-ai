## [1.0.0] - 2026-06-14

### Added
- Initial release of EduCraft AI.
- Native PDF export feature using `fpdf2`.
- DOCX export feature using `python-docx`.
- Integrated with Google Gemini for AI-based test generation.
- Supabase integration for authentication and database.

### Changed
- Migrated from WeasyPrint to `fpdf2` for Windows compatibility.
